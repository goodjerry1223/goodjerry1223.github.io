## 更新 Study Record

1. 将新的 HTML 文档放在 `study-record/<英文短名称>/index.html`。
2. 如文档引用图片、样式或其他本地文件，将这些文件一并复制到该目录，并保持相对路径可用。
3. 在根目录的 `index.html` 中增加一张文章卡片，链接写成 `/study-record/<英文短名称>/`。
4. 提交并推送到 GitHub；GitHub Pages 会发布新的静态文件。

现有两篇文档来自上级目录中的原始文件；站点内保留了完整的图片附件。站点是公开的，新增内容应先确认可以公开分享。
